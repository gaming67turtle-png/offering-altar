# 제물의 제단 (Offering Altar) — Fabric 26.3

탐험한 땅의 경계에 제단을 세우고 제물을 바치면, 바라보는 방향의 **아직 생성되지 않은 땅**이 제물에 따라 정해집니다.

## 사용법
- 제작: 금 주괴(위) / 석재 벽돌·나침반·석재 벽돌 / 석재 벽돌 ×3
- 미지의 땅 쪽을 바라보고 제물을 든 채 제단 우클릭 → 그 방향 90° 부채꼴, 반경 512블록이 "약속"됩니다.
- 이미 생성된 청크는 그대로이고, 이후 처음 생성되는 청크만 바뀝니다. 겹치면 마지막 제물이 우선합니다.
- 빈손 우클릭: 이 제단에서 한 약속 목록 / 웅크리고 빈손 우클릭: 받는 제물 목록
- 블록을 제단 옆에 놓으려면 웅크린 채로 설치하세요.

## 제물 징수자 (Tithe Collector)
땅이 남은 값을 받으러 옵니다. 네더라이트를 바친 땅에서 어두울 때 3마리가 한꺼번에 나타납니다. 플레이어당 5분에 한 무리까지이고, 주변에 이미 있으면 더 나오지 않습니다.
- 파괴수급 능력치: 체력 100, 공격력 12, 방어력 8, 방어 강도 4, 넉백 저항 0.9, 키 1.5배, 화염 면역
- **징수:** 때릴 때마다 인벤토리의 광석·보석(`offering_altar:tithe_valuables` 태그)을 하나씩 빼앗아 갑니다. 빼앗은 물건을 들고 있는 동안에는 디스폰되지 않고, 쓰러뜨리면 전부 돌려줍니다.
- **끌어당기기:** 5~18블록 떨어진 채 시야에 들어오면 8초마다 플레이어를 끌어당깁니다.
- 드롭: 다이아 1~3개(약탈 적용), 금 주괴 2~6개, 25% 확률로 네더라이트 조각, 경험치 50

## 제물 수집꾼 (Tithe Gatherer)
징수자의 하위 버전으로, 다이아를 바친 땅에 어두울 때 2마리씩 나타납니다(플레이어당 4분에 한 무리).
- 체력 30, 공격력 5, 방어력 2, 넉백 저항 0.3, 키 1.1배
- 때릴 때마다 광석·보석을 하나씩 빼앗고 쓰러뜨리면 돌려주지만, 끌어당기기는 못 합니다.
- 드롭: 철 주괴 1~4개, 금 주괴 1~3개, 30% 확률로 다이아, 경험치 20

징수자와 수집꾼의 쿨다운은 따로 계산됩니다.

- 설정의 `guardian`, `guardian_count`, `guardian_chance`, `guardian_cooldown_seconds`로 몹 종류·마릿수·확률·쿨다운을 바꿀 수 있고, 다른 제물에도 붙일 수 있습니다.

설정 항목: `radius_chunks`, `wedge_angle`, `allowed_dimensions`, `danger_mobs`, 그리고 각 제물의 `items`(아이템 ID 또는 `#태그`), `cost`, `biome`(빈 문자열이면 원래 바이옴 유지), `danger`, `ores`.

- 설정을 고친 뒤 `/offering_altar reload`(OP 2단계 이상)로 서버 재시작 없이 적용할 수 있습니다. JSON이 깨져 있으면 기존 설정이 유지됩니다.
- 서버 시작/리로드 때 존재하지 않는 아이템·태그·바이옴·블록·몹 ID와 중복 ID를 서버 로그에 경고로 알려줍니다.
- 위험도 스폰은 어두운 곳(밝기 7 이하)에서만, 평화로움 난이도와 `spawn_monsters` 게임룰이 꺼져 있으면 일어나지 않습니다. 스폰된 몹에는 `offering_altar.danger` 태그가 붙습니다.
- 나침반을 얻으면 레시피북에 제단 레시피가 열립니다.
- 클라이언트와 서버 양쪽에 설치해야 합니다(새 블록 추가). Fabric API 필요.

## 동작 방식
- `ChunkStatusTasks.generateBiomes` 직후에 약속된 4×4 바이옴 셀만 덮어씁니다. 지표(모래/잔디), 나무·식물 같은 지형 장식은 바이옴을 따라가지만, 지형 높낮이(산/평지)는 원래 노이즈 그대로입니다.
- 광석 보너스는 `generateFeatures` 직후, 약속된 청크의 돌/심층암에 작은 광맥을 추가합니다.
- 모드 훅에서 오류가 나도 해당 청크는 바닐라로 생성되고 월드 생성은 멈추지 않습니다.

## 빌드 / 테스트
JDK 25 이상이 설치되어 있어야 합니다. Gradle이 `gradle/gradle-daemon-jvm.properties` 설정에 따라 설치된 JDK를 자동으로 찾습니다.

```
gradlew build              # build/libs/offering-altar-26.3-1.0.0.jar
gradlew runClientGameTest  # 실제 클라이언트로 제단 설치·우클릭·생성 결과 검증
```
